# Review dei rischi Sprint 5

Questa review riguarda il codice locale, non è un penetration test indipendente. L'applicazione resta un'anteprima privata.

| Rischio                                | Protezione e verifica                                                                                         | Limite / azione prima della beta                                                                                                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Escalation moderatore / IDOR           | Ruolo DB attuale su ogni richiesta, CLI esplicita, test 401/403, cambio ruolo invalida accesso immediatamente | Accesso DB/CLI equivale a potere operativo; separare credenziali runtime/migrazioni e valutare MFA moderatori                                                  |
| Doppia decisione / nessun audit        | Lock su report/account e transazione unica; concorrenza reale 204/409, audit unico                            | Proprietario DB può alterare record: audit non immutabile crittograficamente                                                                                   |
| Contenuto rimosso ancora raggiungibile | Vista condivisa post_audience; test ricerca, preview, notifiche, immagini e ripristino                        | Una risposta già autorizzata può essere in volo al momento della restrizione                                                                                   |
| Scritture dopo cancellazione           | Lock account ordinati prima di social/post/media, confronto password sotto lock                               | Verificare questo protocollo su ogni nuova funzione futura                                                                                                     |
| Export di credenziali / dati altrui    | Colonne ammesse esplicite, password attuale, ZIP no-store, test byte/JSON e account distinti                  | Limiti di dimensione richiedono assistenza per account grandi; download salvato resta responsabilità dell'utente                                               |
| Residui dopo cancellazione             | Test reale DB + S3, guasto storage simulato e retry persistente, FK preservano risposte altrui                | Tombstone UUID, report di terzi e audit possono restare pseudonimi: revisione motivata e retention, nessuna promessa di anonimato                              |
| File temporanei export                 | File 0600, nome casuale, rimozione dopo risposta, un export per processo                                      | Crash può lasciare ZIP nel tmp del container/utente. Ispezionare e cancellare residui prima di riuso/condivisione della macchina; pianificare cleanup dedicato |
| Spam / abuso                           | Quote DB per account, quota auth peer persistente, blocchi, deduplica serializzata, upload limitati           | Peer condiviso Next penalizza utenti diversi; niente CAPTCHA/anti-bot distribuito o reputazione. Definire proxy attendibile prima di scala pubblica            |
| Log sensibili                          | Errori pgx/S3 sostituiti da classi; test con email/password/path/token sentinella                             | Controllare anche log dei proxy, Docker, SMTP e strumenti di debug prima del lancio                                                                            |
| Storage irraggiungibile / orfani       | Tombstone durevole e batch retry; riconciliazione esplicita con 24h di grazia                                 | Eseguire riconciliazione periodica e controllare pending; monitoraggio esterno nello sprint beta                                                               |
| Perdita DB/immagini                    | Backup coerente e restore isolato con SHA-256 verificato                                                      | Solo disco locale, copie non cifrate dal tool; niente recovery automatico o registry cancellazioni esterno                                                     |
| Notifiche email perse                  | Coda limitata, reset revoca sessioni, SMTP locale protetto                                                    | Coda non durevole, email non obbligatoria nell'anteprima; retry/outbox e SMTP reale prima della beta                                                           |
| Pubblicazione senza adempimenti        | Bozze privacy/DSA esplicite e pagina informazioni locale                                                      | Titolare, basi giuridiche, contatti, notice pubbliche, comunicazioni agli autori, ricorsi e procedure assistite da definire                                    |

Verifiche automatizzate: test Go con PG/S3, Playwright con tre viewport, lint/tipi/build. Il race detector è previsto dalla CI Linux; non si considera eseguito finché non c'è un risultato reale. Non introdotti deploy HTTPS, inviti, load test o monitoraggio dello Sprint 6.
