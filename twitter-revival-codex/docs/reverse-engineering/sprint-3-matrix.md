# Matrice UI · Sprint 3

Evoluzione indipendente del design Radura esistente e delle strutture descritte nella specifica: feed centrale circa 600 px, avatar laterale, metadati compatti, azioni sotto il testo e conversazione verticale. Nessun nuovo asset esterno, codice o logo proprietario. Non sono state consultate o copiate pagine autenticabili di X; i dettagli sono scelte del progetto, non osservazioni di un archivio storico.

| Schermata           | Elementi / stati                                                                                                      | Responsive e provenienza                                                            | File                                                 |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Home autenticata    | Composer reale, contatore Unicode, pending/error/success, feed seguito cronologico, empty/retry/aggiorna/carica altri | Token e layout Radura esistenti; nessuna card demo nel feed reale                   | `home-timeline.tsx`, `composer.tsx`, `post-list.tsx` |
| Post card           | Autore/profilo, data locale, indicatore modifica, testo escaped, contatori e stato like/repost dal server             | Nomi/testo a capo, azioni tastiera con focus e ARIA pressed; CSS Modules            | `post-card.tsx`, `posts.module.css`                  |
| Azioni proprietario | Form modifica, conferma eliminazione, controlli backend, errore senza perdita testo                                   | Variante inline senza overlay difficile da usare su mobile                          | `post-card.tsx`, `composer.tsx`                      |
| Conversazione       | Post originale, contesto risposta, composer risposta, risposte paginabili                                             | Lista verticale; risposta a una risposta apre il proprio dettaglio                  | `post-detail.tsx`, `app/posts/[id]/page.tsx`         |
| Citazione           | Testo proprio più card originale di un solo livello; riferimento non disponibile se nascosto/cancellato               | Card incorniciata originale Radura, link accessibile all'originale                  | `post-card.tsx`                                      |

| Profilo             | Post e repost reali sotto header e tab esistenti                                                                      | Nessuna anteprima finta o placeholder futuro                                        | `profile-view.tsx`, `post-list.tsx`                  |
| Home anonima        | Tre post inventati, badge DEMO, composer e azioni disabilitati, invito ad accedere                                    | Preserva l'anteprima dichiarata dello Sprint 1; separata dalla timeline autenticata | `timeline.tsx`                                       |
